### 密钥存储与迁移

- 使用兼容现有依赖的 `flutter_secure_storage 10.3.4`，不升级文件选择器等无关依赖。
- 可恢复密钥存于系统加密存储，普通偏好和日志不保存明文。Android 备份规则排除设备绑定的密钥存储。
- 读取失败不会自动清空密钥；写入失败保留旧密钥与鉴权值。并发写入按顺序处理。
- 旧版本只有 SHA-256 摘要，无法逆向恢复明文。原鉴权仍有效；输入已知原密钥可以恢复完整显示，也可以明确选择重新生成。不会静默替换旧密钥。
- 自定义密钥允许 16–256 个符合 Bearer 格式的 ASCII 字符；界面提供明文编辑、校验及错误提示。
- 已验证真实本机 HTTP 传输：自动生成、正确/错误凭据、自定义替换后新密钥可用且旧密钥返回 401。

## 2026-10-01：按录屏补齐悬浮底栏交互

本节为当前实现，取代下方仅对齐标准 Material 3 外观的版本。参考依据是用户录屏中的实际操作，不声称与 GitHub 当前分支逐行或逐像素一致。

### 行为与边界

- 底栏为独立悬浮胶囊，保留脚本、网络、包管理三个入口；不新增独立运行按钮。
- 按下时背景膨胀；横向拖动时连续跟随，利用位置差形成伸缩效果。
- 拖动只更新本地预览，经过中间标签不提交导航、不触发包管理加载。
- 松手吸附最近标签，只提交一次切换；重复选中当前标签不重复加载。
- 系统取消触摸或移出底栏过远时回到原标签，不误切页。
- 横向拖出边界会限制在首尾标签；支持反向拖动、外部选中变化和 RTL。
- 提交后页面以 300ms 横向过渡切换；已访问页面保持局部状态和滚动位置。
- 内容区的横向滑动不会触发切页；平板侧栏保持原外观，侧栏切页不使用动画。
- 系统减少动画设置关闭膨胀、弹性和页面过渡，但保留拖动选择能力。
- 键盘可激活标签，语义选中状态仅反映已提交的页面；长标签可通过 tooltip 读取。

### 实现参数

- 胶囊主体高度 64，水平留白 16，上下留白各 12，底部额外遵守系统安全区，最大宽度 440。
- 选中背景静止高度 52，按压时最大高度 70，水平伸缩有边界限制。
- 位置跟随约 100ms，松手使用 Flutter SpringSimulation；不新增 UI 或动画依赖。
- 保留底栏所需布局空间，避免遮挡现有列表的末尾内容；未修改首页卡片、顶部栏、菜单或列表布局。
- 主要实现为 `lib/ui/app_bottom_navigation.dart`、`lib/ui/app_navigation_pages.dart`；主壳只负责提交切换与原有包加载回调。

### 验证

- 新增和扩展 23 项底栏/页面测试，覆盖预览与提交分离、连续几何变化、取消、反向、边界、外部状态、RTL、键盘、销毁、大字体、安全区、页面状态保留和减少动画。
- 额外提供可选动效导出测试；开启导出时共 24 项通过。
- 全量测试：440 项通过、1 项跳过。
- 静态分析通过；原首页 golden 基线未改动。
- 已人工检查底栏深浅色、拖动中截图和动效关键帧。
- Android 调试包构建成功：`build/app/outputs/flutter-apk/app-debug.apk`；尚未真机验证，也未进行设备性能测量。
