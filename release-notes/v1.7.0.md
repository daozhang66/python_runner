# Python Runner 1.7.0

> 重大更新 · Major update

## 中文

### 终端与 SSH
- **本机终端**：脚本页顶部新增终端入口，本机 shell 内置 `python` / `run` / `scripts` / `pyhelp` 命令，可直接运行脚本或文件（需要终端页开着，输出显示在运行控制台）。
- **多会话标签**：同时开多个终端；支持触摸选择、复制、粘贴。
- **SSH**：保存主机，远程运行脚本，xterm 终端页。密码和私钥存放在加密存储里。
- 已有脚本在运行时再点运行，会先问你：查看正在运行的，还是停止它并运行新的。

### AI 能用终端了（MCP 终端工具）
- 新增独立的「终端」权限，**默认关闭**。开启后 AI 可以：列出、打开、关闭自己的本机终端，发送命令，读取输出，Ctrl+C，等待新输出。
- 你和 AI **共用同一个终端**：你敲的、AI 敲的、输出的内容，双方都看得到。
- **遇到密码怎么办**：终端或脚本停在密码提示时，AI 不会去猜，应用会提醒你（悬浮按钮出现「!」、对话面板出现「去输入」），你从别的 App 切回 Python Runner 时会直接跳到那个终端或控制台，输入完 AI 继续。
- **悬浮 AI 按钮 + 对话面板**：AI 的留言、你的回复都在这里；不必来回切换也能和 AI 说话。面板里有「暂停 AI 使用终端」总闸和可选的「AI 每条命令先问我」（默认关）。
- 不再逐条弹窗——AI 本来就能靠脚本绕过去，弹窗只会添麻烦；真正的控制是权限开关、暂停键和完整日志。

### 安全升级
- 新增「**仅本机访问**」开关：开启后 MCP 只监听本机地址，局域网设备连不上（默认保持原来的局域网访问，重启 MCP 服务后生效）。
- 收紧跨域（CORS）：只回应本机或私有局域网来源的网页，其他来源拿不到答复。
- MCP 的每一次调用（连接、断开、工具、参数摘要、结果、耗时）都**持久保存**，重启后仍在。
- **密码不进日志**：终端和脚本里输入密码的那一行，日志里只记为「隐藏输入」。
- 修复脚本里 `getpass` 报 `GetPassWarning: Can not control echo on the terminal`，提示不再显示为错误。
- 设置页里原来简略的审计列表，换成通往完整「AI 操作」日志的入口。

### 日志升级
- 三套日志：**终端页**、**AI 对话**、**AI 操作**。分片保存，已封存的分片用 gzip 压缩，重启后仍在。
- **简略 / 标准 / 详细**三档真正有区别：标准版是精简摘要（输出只看前几行，AI 调用只看关键项）；详细版是完整内容（每次运行脚本的全部终端输出、完整 JSON、AI 读取终端的记录）。
- 每次运行脚本的输入输出都会记录，并按发起者归类：你运行的进「终端页」，AI 运行的进「AI 操作」。
- 可导出（可读文本或 JSON Lines）、可删除（单个会话 / 7 天前 / 全部）。
- 日志页重新设计：类型标签、按谁操作着色、输出放进等宽框、错误标红。

### 输入体验
- 除密码、令牌、密钥这类必须保证安全的输入框外，其余输入框都允许键盘建议和剪贴板（脚本搜索、运行对话框、SSH 主机、镜像与代理、包名与版本、通用搜索框等）。

### 两个 Python 版本，一起发布
- 以后每次发布都会同时提供两个 APK：
  - `py3.11`：默认版本；
  - `py3.10`：可 pip 安装官方 SciPy / scikit-learn 的 Android 轮子。
- 应用内更新只会提供和你当前安装**同一个 Python 版本**的 APK，不会悄悄换版本。两个版本使用同一签名，可互相覆盖安装。
- 每个 APK 都附带 `.sha256` 校验文件。

### 升级须知
- 「终端」权限是新增的，已经使用 MCP 的用户需要手动开启才能让 AI 使用终端。
- 局域网访问保持原样，不会让你现在的连接方式失效。

## English

### Terminals and SSH
- **Local terminal**: a terminal button at the top of the script page. The local shell has built-in `python` / `run` / `scripts` / `pyhelp` commands that run scripts and files (the terminal page must be open; output appears in the run console).
- **Multiple sessions** as tabs, with touch selection, copy and paste.
- **SSH**: saved hosts, remote script runs and an xterm terminal page. Passwords and private keys live in encrypted storage.
- Tapping Run while a script is already running now asks first: view the running one, or stop it and run the new one.

### The AI can use terminals (MCP terminal tools)
- A separate **Terminal** permission, **off by default**. When on, the AI can list, open and close its own local terminals, send commands, read output, press Ctrl+C and wait for new output.
- You and the AI **share the same terminal**: what you type, what the AI types and the output are visible to both.
- **Passwords**: when a terminal or script stops at a password prompt the AI does not guess. The app tells you (a "!" on the floating button and an "Open" card in the chat), and when you switch back to Python Runner it opens that terminal or console for you. Type it, and the AI carries on.
- **Floating AI button and chat panel**: what the AI says and what you answer. The panel has a pause switch for AI terminal access and an optional "Ask me before each AI command" (off by default).
- No popup per command: an AI that can run scripts can get around it anyway. The real controls are the permission switch, the pause button and the complete logs.

### Security
- New **This device only** switch: MCP listens on the local address only, other devices on the network cannot connect (the default keeps today's LAN access; takes effect after restarting the MCP service).
- Tighter CORS: only web pages from this device or a private network get an answer.
- Every MCP call (connect, disconnect, tool, argument summary, result, duration) is **kept across restarts**.
- **Passwords stay out of the logs**: the line typed at a password prompt is recorded as "hidden input", in terminals and in scripts.
- Fixed `GetPassWarning: Can not control echo on the terminal` from `getpass` in scripts; the prompt no longer shows up as an error.
- The short audit list in settings is replaced by a link to the full AI operations log.

### Logs
- Three logs: **Terminal**, **AI chat** and **AI operations**. Stored in segments, sealed segments are gzip-compressed, kept across restarts.
- **Summary / Standard / Detailed** now really differ: Standard is a digest (a few lines of output, only the essentials of an AI call); Detailed shows everything (all terminal output of every script run, full JSON, what the AI read from terminals).
- Every script run's input and output is recorded and filed by who started it: yours go to Terminal, the AI's to AI operations.
- Export (readable text or JSON Lines) and delete (one session / older than 7 days / everything).
- A redesigned log view: kind labels, colour by who acted, monospace output blocks, errors in red.

### Input
- Except for passwords, tokens and keys, text fields now allow keyboard suggestions and the clipboard (script search, run dialogs, SSH hosts, mirror and proxy, package names and versions, shared search fields and more).

### Two Python versions, released together
- Every release now carries two APKs:
  - `py3.11`: the default;
  - `py3.10`: can pip install the official SciPy / scikit-learn Android wheels.
- In-app updates only offer the APK of the **same Python version** you have installed, so an update never switches Python. Both share one signature and can be installed over each other.
- Each APK comes with a `.sha256` checksum file.

### Upgrade notes
- The **Terminal** permission is new: if you already use MCP, turn it on yourself before an AI can use terminals.
- LAN access stays as it is, so your current setup keeps working.
